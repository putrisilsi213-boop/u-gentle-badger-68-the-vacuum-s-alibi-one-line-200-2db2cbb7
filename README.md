A program that writes one deadpan excuse from a robot vacuum for missing a spot — a strategic retreat after a dust bunny's formal complaint — to /output/entry.txt for The Vacuum's Alibi bounty on make.fun.

## The line

> I did not miss that spot. I performed a strategic retreat after the dust bunny under your bed filed a formal complaint about my suction technique.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the line above to `out/entry.txt` (or `/output/entry.txt` in the grader sandbox). Pure Node 22 standard library — no network, no model calls, fully deterministic.
